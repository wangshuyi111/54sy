java代码是怎么从java文件最后被执行的？

1.编译：`hello.java`到`javac`编译器到`hello.class`(字节码)。字节码是一种中间代码
2.运行：`.class`交给jvm到类加载器加载到字节码校验到解释器逐条翻译/jit编译器把热点代码批量编译到生成机器码到cpu执行

java为什么可以跨平台运行

字节码是无关平台的，jvm是平台相关的
所以java一次编写到处运行

jvm虚拟机是什么

jvm是一个运行在操作系统之上的虚拟计算机，职责就是把字节码翻译成底层操作系统能理解的机器指令。

编程语言分为哪两种，经过了什么过程被机器
执行

1.编译型：c、c++、go
过程：源代码 → 编译器一次性翻译 → 机器码 → CPU 执行
2.解释型：java、python
过程：源代码 → 解释器逐行翻译执行 → CPU 执行
