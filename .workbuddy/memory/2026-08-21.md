## 关键操作要点(可复用)

- 用户全局 `core.autocrlf=true`,混合 LF/CRLF 文件会触发一堆 warning
- **解决方案**: 每次 git 操作加 `-c core.autocrlf=false` 临时绕开,不要改全局配置
- **示例**: `git -c core.autocrlf=false commit -m "..."` / `git -c core.autocrlf=false push origin main`
